# QuickDidi project guide

QuickDidi is a marketplace for booking help with household tasks such as cleaning, dishwashing, and cooking. A Didi is a service provider.

- [Project scope](scope/README.md) explains who uses the product and what the current version supports.
- [User workflows](workflows/README.md) follows customers and Didis through each page.
- [Project graph](architecture/README.md) shows how the web app, API, and database fit together.
- [What's missing](roadmap/README.md) lists release blockers and the suggested order to fix them.
- [Work log](../memory.md) records completed work, verification, and open items.

For local development, the [existing project map](../PROJECT_MAP.md) contains more technical background. Use the gap list above for current release status.
